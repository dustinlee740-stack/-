4. 쿼리 비교 모듈 (Rule-Based Query Diff)							
예상 난이도 : 3							
A쿼리(운영계)·B쿼리(분석계) 간 합계 차이의 원인을 추적하는 모듈							
※ 이 섹션 전체가 신규 추가 영역. 입력 처리, 스키마 매핑, AST 구조 비교, Row diff, 차이 귀인, 리포트 생성 포함

3	스키마 매핑 딕셔너리 구축	운영계(Oracle) 테이블·컬럼·PK ↔ 분석계(Hive) 테이블·컬럼·PK 간 N:M 매핑 관리. 컬럼 정의서 기반 초기 자동 구축 + 수동 보정 UI. Row diff 시 매칭 키 매핑 포함	DE/백엔드	추가 ★	3	4	테이블·컬럼이 상이하여 직접 비교 불가하므로 매핑 딕셔너리가 절대 전제 조건. 컬럼 정의서 자동 파싱으로 초기 구축하되 예외 케이스 수동 보정 필수. No.2 구조 비교와 No.5 Row diff 양쪽의 기반 모듈
4	"	Row 데이터 수집 파이프라인"	운영계·분석계 각 망에서 쿼리 실행 후 Row 데이터를 로컬(비교 모듈 서버)로 전송. MVP: 사용자가 CSV 수동 업로드. 확장: 각 망에 경량 에이전트 배포 + 암호화 파일 전송. 매칭 키 지정 UI 포함	DE/백엔드	추가 ★	3	3	망 분리 환경에서 단일 모듈의 양쪽 DB 접근 불가. 에이전트 자동화는 보안 심의 완료 후 전환. 사용자가 A·B 매칭 키 컬럼을 지정하는 UI 필수
5	Row 단위 diff 엔진	매칭 키 기준 A·B Row 데이터 outer join 후 3가지 차이 분류: ①A에만 존재(B 누락), ②B에만 존재(A 누락), ③양쪽 존재·값 상이. 각 분류별 합계 기여분 산출하여 총 차이(예: 100)를 행 단위로 분해. 대용량 시 drill-down 전략(GROUP BY 단위 축소 → 차이 구간 특정 → Row 비교) 적용	백엔드	추가 ★	3	7	pandas merge(outer join + indicator)로 구현 가능. 매칭 키 기반 행 대응 후 셀 단위 diff는 정형 데이터 비교 표준 기법. 대용량(수백만 행) 시 전수 비교 대신 drill-down 집계 쿼리 생성으로 차이 구간 좁히기 필요. 모듈의 핵심 가치 산출 단계
6	차이 귀인 엔진	구조 비교(No.2) 결과 + Row diff(No.5) 결과를 결합하여 원인 분류. ①쿼리 차이 기인: 특정 절(JOIN/WHERE/집계) 차이가 누락·불일치 행과 대응 → 해당 조건 특정. ②원천 데이터 차이 기인: 쿼리 구조 동일한데 Row 차이 존재 → "분석계 미적재 데이터" 등으로 분류 후 사람 판단 위임	백엔드	추가 ★	3	5	"구조 차이 유무"(이진 판별) × "Row diff 패턴"(3가지 분류)의 조합이므로 규칙이 단순. 인과관계 증명이 아닌 귀인 분류(쿼리 차이 vs 데이터 차이)만 수행
7	비교 결과 리포트 생성기	차이 요약(총 gap) → Row diff 상세(누락 행·값 차이 행 목록) → 원인 귀인(쿼리 차이/데이터 차이) → 후속 조치 가이드를 통합한 리포트 생성. 심각도(Critical/Warning/Info) 분류.
