1단계: 사용자 본인인증 여부 확인

2단계: 미성년자(14세 미만) 여부 확인 → 해당 시 기존 10만원 한도 적용

3단계: 법인 계정 여부 확인 → 해당 시 계약 한도 적용

4단계: 당일 누적 충전액 조회

5단계: (요청 금액 + 누적액) > 1,000,000원 → 초과 안내 및 차단

6단계: (현재 잔액 + 요청 금액) > 2,000,000원 → 잔액 한도 초과 안내 및 차단

7단계: 충전 처리 후 AML 시스템 누적액 전달
