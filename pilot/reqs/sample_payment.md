# 요건: 결제 환불 자동화 검토

## 배경
가맹점에서 발생한 환불(refund) 요청을 사용자가 모바일 앱에서 직접 처리할 수 있도록 한다.
현재는 콜센터를 거쳐야 하므로 처리 시간이 길고, IAS의 거래 원장(승인/지불/환불)과
연계되는 흐름의 일부 단계가 수기로 진행된다.

## 요구사항
- 사용자 앱에서 결제 내역(transaction history)을 조회하고, 특정 거래에 대해 환불 신청 가능
- 환불 신청 시 카드 라이프사이클 상태(CMS) 확인 — 정지/해지된 카드의 환불 처리 정책
- 가맹점(merchant)에 알림 발송 및 정산(settlement) 영향 반영
- 부정 거래(fraud) 패턴 감지 시 자동 보류 후 검토 큐에 적재

## 제외
- B2B 정산 변경은 본 요건에서 제외
- 해외 결제 환불은 차후 단계
